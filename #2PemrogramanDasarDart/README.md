### Soal 3

Rangkumlah materi dari codelab ini menjadi poin-poin penting yang dapat Anda gunakan untuk membantu proses pengembangan aplikasi mobile menggunakan framework Flutter.

**Jawaban:**

Dart adalah bahasa pemrograman yang digunakan dalam fllutter untuk  memudahkan developer membuat apklikasi mobile, web, dan desktop.

**1. KELEBIHAN DART**

Dart dibuat untuk menggabungkan kelebihan dari banyak bahasa pemrograman modern. Yaitu:
    **Productive Tooling**
    **Garbage Collection**
    **Type Annotations**
    **Statically Typed**
    **Portability**
Karena kelebihan tersebut, dart dipilihin menjadi bahasa utama flutter.

**2. CARA KERJA DART**

Kode dart bisa dijalankan dengan dua cara, yaitu:

   **1. Dart Virtual Machine (VM)**
    Digunakan saat proses pengembangan aplikasi. Biasanya dipakai ketika debugging atau saat menggunakan fitur hot reload.
   **2. Kompilasi ke JavaScript**
    Digunakan untuk aplikasi web agar bisa dijalankan di browser.

Selain itu, Dart memiliki dua metode kompilasi:
   **JIT (Just-In-Time)**
    Digunakan saat pengembangan aplikasi karena mendukung debugging dan hot reload.
   **AOT (Ahead-Of-Time)**
    Digunakan saat aplikasi sudah siap dirilis karena performanya lebih cepat.

**3. STRUKTUR DASAR BAHASA DART**

Dart menggunakan konsep OOP, yang artinya program dibuat menggunakan objek dan class. Class adalah blueprint, sedangkan object adalah hasil dari class tersebut.
